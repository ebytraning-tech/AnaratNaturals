# Anarat Naturals

A responsive storefront starter for Anarat Naturals, built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy
Import this repository into Vercel. No build command is required; the project can be deployed as a static site.

## Current starter features
- Responsive storefront landing page
- Product category filters and sample product cards
- Shopping bag with quantity and subtotal
- Cash on Delivery positioning
- About/story and newsletter sections

## Before accepting real orders
Replace the sample products and prices with the actual catalogue. Connect a secure backend/database, order creation, delivery charges, customer details, and order notifications. The current cart is a front-end demo and does not submit or store real orders.
